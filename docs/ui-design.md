# UI 设计

## 窗口

- 默认 1200×700，最小 820×500
- 强制 X11 后端（GNOME Wayland 标题栏缺陷，见 [pitfalls.md](pitfalls.md)）
- 深色主题为默认，可切换浅色
- 中文字体：启动时按候选路径探测加载系统字体
  （Noto Sans CJK → 文泉驿 → DroidSansFallback → arphic），
  注册为 `Proportional` / `Monospace` 的回退字体

## 整体布局

```
┌──────────────────────────────────────────────────────┐
│ 顶栏：♪ 标题 — 艺术家 《专辑》   [+添加][📁文件夹]│[打开][保存] │
├──────────────────────────────────────────────────────┤
│ [播放列表] [歌词]                          [🌙 深色] │
│ ┌──────────────────────────────────────────────── ┐ │
│ │ 1  歌曲A — 歌手                        3:45  ✕ │ │
│ │ ▶2 歌曲B — 歌手(蓝色高亮+均衡器)      4:12  ✕ │ │
│ │  …                                              │ │
│ │ 共 N 首 · 双击播放 · 右键更多操作    [🗑清空列表] │ │
│ └──────────────────────────────────────────────── ┘ │
├──────────────────────────────────────────────────────┤
│ [⏮][▶][⏹][⏭] [→顺序播放] │ 1:23 ═══════╪═══ 3:45 │🔊│
└──────────────────────────────────────────────────────┘
```

控制栏为**单行紧凑布局**（用户明确要求）：传输按钮 + 模式 + 进度 + 音量，
文件操作放顶栏工具栏，「清空」放列表底部。

## 控制栏细节

- 传输按钮：Material Symbols 图标，统一 `min_size(34×30)` 保证对齐
- 播放/暂停图标 24px，其余 20px（同一按钮框内居中）
- 进度条：
  - 当前时间**右对齐**、总时长**左对齐**，紧贴滑块两端
  - 滑块宽度 = `available_width() - TAIL_W(200)`，TAIL_W 为右侧
    （时间+音量）的预留宽度
  - 拖动中显示 `seek_drag` 预览值，松手（`drag_stopped`）才 seek
- 音量：滑块 70px + 图标（静音时自动切换 volume_off 图标）
- 错误提示条：底部红条 + ✕ 关闭

## 播放列表行

| 元素 | 设计 |
|---|---|
| 序号列 | 30px 固定宽，等宽字体右对齐 |
| 当前曲 | 4 柱**跳动均衡器**动画（正弦相位错开，播放 20fps / 暂停静止），主题色 |
| 标题 | 当前曲主题色加粗；超长截断省略号 |
| 艺术家 | 弱化色，`— ` 前缀 |
| 时长 | 等宽字体右对齐 |
| 移除按钮 | 红色醒目（淡红底红字，悬停加深），Material close 居中绘制 |
| 行背景 | 当前曲：主题色 α=32；悬停：`weak_bg_fill`；圆角 4px |
| 交互 | 整行双击播放、右键菜单；行 hit 区域**排除行尾按钮区**（防点击遮挡） |

### 移除二次确认

点击 ✕ → `Popup::from_toggle_button_response` 悬浮确认框：
曲目名（>14 字截断）+ [移除]（红）[取消]。点外部任意处关闭。

### 右键菜单

`▶ 播放` / `🗑 移除`（红字），均带 Material 图标对齐。

## 图标系统

`egui_material_icons`（Material Symbols 字体）：
- 启动时 `initialize(ctx)` 注册，作为 `Proportional` 回退字体
- 文本内混排：`format!("{} 添加文件", ICON_ADD.codepoint)` 直接生效
- 自绘（painter）：需指定字体族
  `FontFamily::Name(egui_material_icons::FONT_FAMILY.into())`
- 语义图标映射：模式 → `arrow_forward/repeat/repeat_one/shuffle`，
  音量 → `volume_up/volume_off`

## 布局关键经验（egui）

1. egui `Slider` 以 `spacing().slider_width`（默认 100px）自渲染，
   **无视 `add_sized` 宽度** → 必须先 `ui.spacing_mut().slider_width = w`
2. `ui.horizontal` 内容默认垂直居中（`Align::Center`），但按钮框高随内容变化，
   需 `min_size` 统一
3. 后注册的组件在点击测试中位于顶层 → 整行 hit 层要给行内按钮让位
4. `scroll_to_me` 必须在 ScrollArea 闭包内调用

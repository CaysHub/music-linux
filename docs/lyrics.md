# LRC 歌词设计

参考 MusicPlayer2 的 Lyric.cpp 行为子集，手写实现（约 120 行纯函数）。

## 解析（lyrics/lrc.rs）

### 编码探测（顺序）

1. UTF-8 BOM（`EF BB BF`）→ 去除后按 UTF-8
2. 尝试纯 UTF-8
3. GBK 回退（`encoding_rs::GBK`，中文 LRC 极常见 GBK）

### 语法支持

| 语法 | 说明 |
|---|---|
| `[mm:ss]` `[mm:ss.xx]` `[mm:ss.xxx]` | 标准时间标签 |
| `[mm:ss:xx]` | 旧式百分秒，归一化为点分 |
| `[00:01.00][00:05.00]歌词` | 压缩 LRC：行首多时间标签展开为多行 |
| `[offset:±ms]` | 整体偏移，正值歌词提前（时间减 offset） |
| `[ti:]` `[ar:]` `[al:]` `[by:]` | 元数据标签，忽略 |

解析结果按时间升序排序，纯文本/空输入返回 `None`。

### 时间换算

```rust
mm * 60_000 + ss * 1_000 + 小数毫秒
// 小数位按位数换算：1 位=×100ms，2 位=×10ms，3 位=原值
```

## 加载

播放曲目时自动加载**同目录同名** `.lrc`（`audio.with_extension("lrc")`）。
GBK 自动探测。无歌词时歌词页显示新建入口。

## 编辑与保存

- 歌词标签栏根据同名 `.lrc` 是否存在显示“新建歌词”或“编辑歌词”，并显示目标路径
- 编辑器直接载入原始歌词文本，保留元数据、多时间标签及原有排版
- 可粘贴带时间轴的 LRC，界面实时显示识别到的歌词行数
- “插入当前时间”会在文本末尾插入当前播放位置的 `[mm:ss.xx]` 标签
- 保存前必须至少解析出一行带时间轴的歌词，避免误写纯文本文件
- 保存使用 UTF-8 编码，写入歌曲同目录、同文件名的 `.lrc`，成功后立即刷新展示
- 编辑草稿绑定开始编辑时的歌曲路径；编辑期间切歌不会将歌词写到新歌曲名下
- 支持 `Ctrl+S` 保存

## 展示（ui/lyrics_view.rs）

- 每行歌词使用全宽 Label 居中展示，点击区域仍覆盖整行宽度
- 当前行：字号 22、加粗；其余行字号 16
- 当前行与 Pin 模式使用相同的横向进度渐变：未播放部分为弱色、已播放部分为青绿色强调色、推进边缘为暖色；
  未来 8 秒内即将播放的歌词逐步提亮，刚播放过的歌词在 6 秒内淡出
- **自动滚动居中**：当前行 `scroll_to_me(Align::Center)`（必须在 ScrollArea
  闭包内调用才生效）
- **手动滚动暂停跟随**：检测到鼠标滚轮后暂停自动滚动 3 秒，seek/切歌后立即恢复
- **点击歌词行跳转**：每行 Label 设 `Sense::click()`，点击即 `engine.seek(行时间)`
- 空行显示 `♪` 占位
- 前后各留 35% 高度的空白，使首尾歌词也能滚动居中

## 置顶迷你歌词（ui/mini_player.rs）

- 顶栏“置顶歌词”将主窗口切换为 460×78 的无标题栏双行窗口，并设置为 `AlwaysOnTop`
- 控制行固定 36px，歌词行固定 42px，无外边距或额外分隔行
- 第一行左侧为拖动把手、上一曲、播放/暂停、停止、下一曲，右侧为播放模式、恢复和关闭；中间显示歌名及四柱均衡器动效，不显示音量、进度条与时间
- 第二行仅显示当前歌词；拖动这一行也可移动窗口
- 普通 LRC 只有逐行时间，着色进度按“当前行开始 → 下一行开始”计算；末行回退到曲目时长或 4 秒
- 已播放部分使用强调色，推进边缘使用暖色渐变；歌词过长时动态缩小字号并保持单行
- 恢复主界面时还原标题栏、可调整尺寸状态、进入前的窗口大小及最大化状态，并将非最大化窗口居中；主窗口先临时置顶，失去焦点后自动恢复普通层级
